# 记住登录（2026-10-09）

登录页增加默认不勾选的“记住登录”。不勾选仅在当前进程使用 Token；勾选并校验成功后，Rust 将 Token 保存在系统安全存储中。启动时只恢复通过此开关保存的登录，并在线校验身份后进入主页。旧版仅有 remembered 标记的保存项不会自动恢复。

退出登录清除保存项和记忆开关。已失效的保存令牌返回手动登录并清除记忆；临时校验失败保留保存项，留在登录页，允许取消勾选后重新输入。系统安全存储不可用时明确提示取消“记住登录”重试，不将 Token 写入普通文件、浏览器存储或 SQLite。

本地验证：完整 `npm run check`、Rust 格式和严格 Clippy 通过；新增 3 项安全存储偏好与恢复单元测试不访问实际凭据。7 个实际 React 浏览器模拟 IPC 场景通过，覆盖默认不勾选、两种登录选择的重启、退出登录、保存令牌失效、临时校验失败和失败登录不保存。

本轮未读取实际系统凭据、调用真实云效或打包安装。验证日志及登录页截图保存在 `artifacts/login-memory-20261009/`。跨平台真实安全存储行为仍需安装环境验证。

## 启动恢复与浏览器授权登录（2026-10-10）

启动先显示独立的登录恢复状态，保存的 PAT 或 OAuth 授权校验结束前不渲染登录表单；有效授权直接进入主页，静默恢复不显示登录成功或“打开登录页”提示。无保存项、授权失效或临时网络失败时再显示登录卡片。临时失败保留保存项，失效授权沿用退出清理；两个登录 Tab 为“授权登录”和“填写 PAT”，保留默认不勾选的记住登录选择。

依据[云效 OAuth 2.0 官方说明](https://help.aliyun.com/zh/yunxiao/developer-reference/oauth-2-0-authorization-support-documentation)实现公共客户端流程：发现授权端点、动态注册客户端、系统浏览器授权、S256 PKCE、随机 state 和本机随机端口回调、授权码换令牌。所有凭据和网络处理在 Rust，不要求应用密钥，不向 renderer 返回访问／刷新令牌。记住登录使用独立系统凭据条目；普通数据库仅保存登录方式和偏好。请求前自动刷新将到期的访问令牌，并发请求共用一次刷新，刷新令牌轮换后更新保存项。取消和退出关闭旧授权，刷新中的旧会话不会恢复已删除凭据；PAT 与 OAuth 切换清除另一种保存项。历史查询和提交恢复也使用同一授权会话。

验证覆盖 14 项 OAuth Rust 专项测试、9 个实际 React 启动／授权／PAT 模拟场景及 7 个既有记住登录回归场景。整体验证通过 178 项前端测试、136 项 Rust 测试（1 项既有真实只读测试忽略）、类型检查、生产构建、严格 Clippy、Rust 格式和 10 项流程检查。最后仅修正登录说明的卡片边界布局，重新通过类型检查、构建、9 个界面场景及 980／1280／1440 像素卡片内部边界验证；Rust 输入未变化，复用最终后端结果。

当前编译源码与最终完整检查期间指纹一致；最后样式修正也有独立前后指纹。浏览器检查自带来源保护且通过，检查结束后只有并行主会话的独立 history-filters-check.mjs 变化，它未被本专项脚本引用。不将本回执当作主会话历史筛选界面的验收。初次编译包含本轮错误返回类型及主会话临时私有函数访问错误，修正完成后最终检查通过；早期日志保留。仅匿名读取实际云效授权元数据确认官方端点，没有读取真实 PAT、发起实际客户端注册／用户授权或云效业务写入，也没有打包覆盖安装。日志、截图、源码指纹和回执位于 artifacts/ui-login-oauth-side-20261010/。
