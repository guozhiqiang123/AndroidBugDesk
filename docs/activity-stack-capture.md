# 广告问题与 Activity 任务栈补采方案

确认日期：2026-10-15。

## 结论

ADB 可以读取设备当前仍保留的 Activity 任务栈和最近任务，但不能提供永久、完整的页面访问历史。客户端将“Activity任务栈”作为独立补采项，通过目标包过滤后的以下只读命令采集：

- `adb shell dumpsys activity -p <package> activities`
- `adb shell dumpsys activity -p <package> recents`

`activities` 用于读取当前 ActivityRecord、Task、前后台与暂停状态，`recents` 补充系统仍保留的最近任务记录。应用进程被杀、任务被清除或系统回收后，较早记录可能缺失，因此附件和 `receipt.json` 必须明确说明“不是永久操作历史”。命令参数固定由项目包名映射生成，不接受用户输入的任意 shell 片段。

## 问题类型与默认组合

新增“广告”问题类型。所有类型继续默认选择“现存日志”和“当前截图”，专项默认项如下：

| 问题类型 | 专项默认项                                                                                         |
| -------- | -------------------------------------------------------------------------------------------------- |
| 功能     | 当前界面层级、应用与进程状态、Activity任务栈                                                       |
| UI       | 当前界面层级、窗口与显示状态、Activity任务栈                                                       |
| 多语言   | 当前界面层级、语言与字体配置、窗口与显示状态                                                       |
| 动态过程 | 当前界面层级、应用与进程状态、Activity任务栈                                                       |
| 崩溃     | 崩溃日志、历史进程退出记录、应用与进程状态、Activity任务栈                                         |
| ANR      | 崩溃日志、历史进程退出记录、应用与进程状态、Activity任务栈、窗口与显示状态、当前应用内存、系统报告 |
| 广告     | 应用与进程状态、Activity任务栈                                                                     |
| 性能     | 当前应用内存、现存帧统计、CPU与进程状态                                                            |
| 网络     | 网络配置与统计                                                                                     |
| 数据     | 存储空间与权限、应用与进程状态                                                                     |

广告默认项覆盖广告 SDK/宿主进程状态、广告 Activity 或落地页任务关系、现存应用日志和现场截图。网络证据仍保留为手动选项，避免所有广告问题默认采集较大的整机网络统计。

## 移除持续前台 Activity 监听

设备读取不再调用 `dumpsys activity activities` 或 `dumpsys window windows` 获取前台页面，也不再启动每秒一次的后台 ADB 观察任务。设备刷新只读取设备、应用版本及资源信息；补采开始和结束不再暂停或恢复页面观察器。

“Bug所在页面（选填）”保留为人工字段，用户填写或清空后，设备刷新不会覆盖。旧草稿中已经保存且能归属于目标包的页面继续兼容读取；旧版误存的 Launcher 或其他包页面沿用既有启动清理规则。

## 验收边界

- “广告”可以保存到草稿、选择记忆、提交描述和历史筛选。
- 广告默认勾选日志、截图、应用与进程状态、Activity任务栈。
- 功能、UI、动态过程、崩溃和 ANR 默认勾选 Activity任务栈；多语言、性能、网络和数据不默认勾选。
- 任务栈附件包含 `activities` 和 `recents` 两条目标包过滤命令及逐项回执。
- 打开页面、刷新设备和等待补采期间均不存在常驻前台 Activity ADB 轮询。
- 人工填写或清空“Bug所在页面”后刷新设备，值和人工来源保持不变。
