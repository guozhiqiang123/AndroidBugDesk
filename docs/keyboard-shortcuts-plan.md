# 新建提交快捷键方案

确认日期：2026-10-15。

## 目标与范围

参考 Asterlyn 的命令与快捷键分离、单一窗口监听器、录制时优先处理、执行时重新校验可用状态等原则，为 Android Bug Desk 增加一套收敛的应用内快捷键。首版只覆盖“新建提交”页的七个既有动作：

| 动作 ID               | 按钮         | 默认快捷键      |
| --------------------- | ------------ | --------------- |
| `newIssue`            | 新建问题     | `Primary+N`     |
| `environmentSnapshot` | 设备环境快照 | `Primary+E`     |
| `postCapture`         | 补采证据     | `Primary+G`     |
| `importAttachments`   | 导入附件     | `Primary+O`     |
| `saveDraft`           | 保存草稿     | `Primary+S`     |
| `exportEvidence`      | 导出本地证据 | `Primary+D`     |
| `submissionPreview`   | 进入提交预览 | `Primary+Enter` |

`Primary` 在 macOS 显示和匹配 Command，在 Windows/Linux 显示和匹配 Control。快捷键只在应用窗口获得焦点且位于“新建提交”页时生效，不注册系统全局热键。

## 收敛后的架构

1. 每个动作使用固定 ID。按钮继续拥有原来的业务处理、禁用条件、错误提示和确认弹窗；快捷键只查找对应按钮并触发同一次点击，不复制业务逻辑。
2. 使用一个窗口级 `keydown` 监听器。未匹配、正在输入法组合、按键长按、已被组件处理、弹窗打开或按钮不可用时不执行动作。
3. 只支持一个按键段，必须包含 `Primary`，可额外包含 `Shift`。首版不支持连续键、单独字符、Alt/Option、系统全局快捷键或任意脚本。
4. 设置页新增“快捷键”卡片。每行显示动作、当前组合、录制和恢复默认；提供“全部恢复默认”。点击录制后，下一次合法组合直接保存，Escape 取消录制。
5. 本机只持久化相对于默认值的覆盖项，结构版本固定为 `v1`。配置不随云效账号退出而清除；未知动作、非法组合、重复组合和超限配置不会写入。
6. 按钮上的可见 `kbd`、`aria-keyshortcuts` 和设置页展示都从当前生效配置生成，修改后立即一致更新。

## 编辑和系统快捷键保护

普通输入期间只消费与七个动作精确匹配的组合。以下组合不能被录制为应用动作：

- 复制、粘贴、剪切、全选、撤销、重做和查找：`Primary+A/C/V/X/Y/Z/F`，包含常见的 Shift 变体；
- 常见正文格式：不带 Shift 的 `Primary+B/I/U`；
- macOS 窗口或系统组合：`Primary+Q/W/H/M/Space/Tab`；
- Windows/Linux 窗口关闭组合 `Alt+F4`，以及任何不含 `Primary` 的组合；
- Tab、方向键、Escape、Space 等组件导航按键。

因此 `Ctrl/Cmd+C`、`Ctrl/Cmd+V`、撤销重做、查找、全选和 Markdown 常用编辑组合继续交给输入框或编辑器。快捷键录制状态本身会接管按键并显示保留键或冲突原因，退出录制后恢复正常输入行为。

## 冲突与执行边界

- 七个动作不能使用相同组合；发生冲突时显示冲突动作名称，不静默替换。
- 快捷键触发前重新读取当前 DOM 按钮；按钮不存在、隐藏或 `disabled` 时不消费按键，也不绕过项目配置、设备连接、采集进行中、字段校验或提交冻结门槛。
- 任一 `aria-modal=true` 弹窗打开时暂停页面动作快捷键，避免在提交预览、补采、删除确认或更新弹窗后方误操作。
- 录制器是唯一可以在设置页接管组合的入口；Escape 只取消录制，不改变当前配置。

## 验收标准

- 七个按钮显示与设置一致的跨平台快捷键提示，键盘触发与鼠标点击走同一处理路径。
- 自定义组合即时生效并跨重启保存；单项和全部恢复默认有效。
- 重复组合、保留编辑组合、缺少 Primary 的组合均不能保存，并显示对应原因。
- 输入框及 Markdown 编辑器中的复制、粘贴、剪切、全选、撤销、重做、查找和格式化行为不被应用快捷键抢占。
- 弹窗打开、按钮禁用、其他 Tab、输入法组合和按键长按不会误触发动作。
- 前端纯逻辑测试、Rust 持久化／校验测试、完整应用测试、类型检查、生产构建、严格 Clippy 和实际 React/mock IPC 场景全部通过。

## 本轮不做

- 系统级全局热键、两段式快捷键、多个候选绑定、导入／导出快捷键配置；
- 历史提交、设置页自身操作、弹窗内部按钮及 Markdown 工具栏快捷键；
- 用快捷键直接绕过确认弹窗、字段校验、设备连接或云效提交门槛。
