# 测试人员操作说明（0.1.0 整合评审）

1. 每次打开客户端立即展示授权令牌输入页，输入框为空。启动不读取钥匙串，也不自动调用云效校验，即使旧版本曾保存过令牌。用户手动输入自己的令牌并点击“确定”后才校验；成功进入主界面，失败停留登录页。界面不再提供“记住登录”，当前授权仅在本次进程内使用。项目和 Bug 字段的选择记忆仍保留。
   登录卡片在窗口水平、垂直居中，校验提示显示在卡片内。只有“确定”提交按钮，也可按回车确认，不提供“清除授权”按钮。
2. 主界面只有“新建提交”和“历史提交”。顶部连接 USB 设备，刷新列表并明确选择设备；未检测到 ADB 时选择官方 Platform Tools 中的 adb。项目与关键字段采用双列表单，按卡片分组。
3. 从 API 返回的组织、项目列表选择目标。首次使用不预置示例项目。令牌有效后，项目权限不足或网络失败会留在主界面供重试；运行中确认令牌失效则返回登录。
4. 补充标题、问题描述、负责人、迭代、版本及项目返回的关键字段。验证者、优先级、严重程度、参与者、抄送、标签等按实际字段配置显示。下拉值来自 API；无选项会提示，不猜取值。新增未支持的必填字段会阻止提交。
5. 每次下拉选择自动记忆，下一份新草稿按账号、组织、项目、Bug 类型恢复。删除的选项不恢复。组织和项目按账号记忆。标题、描述和任意文本不作为选择偏好保存。
6. 填写包名、业务方向及固定 Jenkins 构建 URL，开始采集。复现后记录问题并截图，系统自动等待问题后30秒并生成前120秒/后30秒窗口副本及范围回执。采集中禁止提交；本地进度刷新保留未保存的描述。实际范围、时钟估算、初始缓冲区不确定项与断线缺口分别展示，经过30秒不表示完整覆盖。提前停止或退出会保留中断，重新打开不能补造时间；使用“恢复中断窗口记录”固定现有证据。自动失败项人工补齐并注明来源。
7. 按需点击“采集系统报告”，绑定草稿原设备，最长两分钟；失败保留记录和缺口，不上传不完整输出。可导入并确认 PNG/JPEG、MP4、日志、系统报告 ZIP 和所需样例。补齐步骤、结果、频率、应用及设备信息、设备当时生效的云控。保存草稿，清空待补项，预览核对目标项目、固定构建、描述和附件。获得本次真实写入授权后才进行真实提交验收。
8. “历史提交”保留本机持久回执及恢复入口，另分页读取当前账号在当前项目创建的云效 Bug。权限不足或失败明确显示，不当作零历史。创建结果待核对时必须核对原工作项；已创建但证据未齐时恢复原工作项，不能重复创建。
9. 旧草稿、回执和不可变证据包保留。旧版没有账号/项目绑定的未提交草稿必须新建目标项目草稿并补入需要的信息后再提交，避免投递到错误项目。

不要在聊天、截图、日志或草稿中填写令牌。退出登录停止采集并清除授权。登录校验需要组织管理「用户」只读权限，组织、项目、成员、字段及历史还需对应读取权限；仅工作项读写可能不足。当前真实写入仍未授权，各平台安装、安全存储及完整 USB/媒体提交仍待验收。

日志可展开“生成脱敏副本”，输入精确替换文本，生成后重新预览并确认；原文件不被修改，原副本自动取消上传选择，替换不保证完全脱敏。派生副本的范围/文本替换回执一起确认或取消；不能单独移除回执，移除关联副本会成组移除回执。导出和提交均检查所选派生证据的回执完整性，原始 ZIP 与历史提交保持不可变。

菜单底部显示本次验证用户昵称，缺失时回退姓名或“云效用户”；头像仅在响应实际提供受信地址时加载，失败显示首字。头像由 Rust 无凭据下载，renderer 不直接联网。退出或授权失效清除用户展示。
